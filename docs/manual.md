## 第一章　前言

### 一、目的

作業場所有害物之濃度可以直讀式儀器或感測器於場域內多點量測，再以空間內插方法繪製濃度分布圖，此方法可協助事業單位找出高濃度區位、推斷逸散源方向，或作為通風改善、監測點位規劃及改善前後比較之參考。

本手冊說明以直讀式儀器量測並製作濃度分布圖之方法，包括量測規劃、現場量測、資料整理、資料檢核、製圖、圖面驗證與補點。手冊所述之計算方法涵蓋本計畫開發之大型語言模型技能（以下簡稱 Skill）及網頁製圖工具 ConcTour，使用者得依需要擇一使用。

### 二、適用範圍

（一）室內、作業狀態於量測期間污染物濃度相對穩定之作業場所。

（二）以直讀式儀器或感測器，於同一高度（原則為呼吸帶高度 1.5 公尺）量測單一氣狀或粒狀污染物(氣膠)之水平分布。

（三）場域以矩形為原則。L 形或有隔間之場域，宜分成數個矩形區域分別量測及製圖。

### 三、使用限制

（一）濃度分布圖係以有限測點之實測值推估各位置之濃度，僅供區位判斷及管理參考，不得作為法定作業環境監測、時量平均容許濃度（TWA）或短時間時量平均容許濃度（STEL）暴露等評估之替代。

（二）一張分布圖僅代表單一污染物、單一時段及單一高度之濃度分布。此外對總量型儀器（如光離子化偵測器PID）無法分辨混合物中之個別成分，應注意避免作為單一污染物濃度指標。

（三）量測期間作業狀態應維持穩定。批次操作、間歇排放或作業狀態改變時，所得分布圖可能不具代表性；作業造成濃度變化時，應於變化之時段另行量測，並重新製圖。

（四）不適用於室外、半戶外或風向變化大等之場域。

（五）測點未涵蓋之區域屬推估值，不確定性較高。阻隔物兩側之實際濃度可能不連續，圖面以斜線遮蓋設備區，惟計算時仍視為連續面。

（六）圖面最高值可能低於實際現場最高值，色階依各組資料之濃度範圍配置，判讀時應同時檢視色階數值。

（七）工具所用之之克利金法採線性變異函數、slope ＝ 1、nugget ＝ 0 固定設定，雖為實驗測定最穩定之結果，但對濃度之估計仍可能存在偏差，對濃度分佈結果有疑慮者應尋求專業人員判讀。

### 四、名詞定義

| 名詞 | 定義 |
|:---|:---|
| 直讀式儀器 | 可於現場直接讀出濃度之儀器，如光離子化偵測器（PID）、電化學式氣體偵測器、粒子計數器及低成本感測器。 |
| 場域 | 欲繪製濃度分布圖之矩形範圍。座標原點訂於場域左下角，X 軸向右、Y 軸向上，單位為公尺。 |
| 測點 | 場域內實際量測濃度之位置，以測點編號（如 P01）及 X、Y 座標表示，座標記至小數點後一位（0.1 公尺）。 |
| 障礙區 | 設備本體與基座、樓梯、軌道、隔間、儲架等無法站立量測之區域。製圖時以斜線遮蓋，不呈現濃度。 |
| 逸散源 | 污染物可能逸出之位置，包括設備接口、開放液面、人員操作點及通風不良處。 |
| 標準資料表 | 本計畫訂定之資料格式，記錄場域基本資料及各測點座標與濃度，Skill 與 ConcTour 均可讀取。 |
| 點位量測時間表 | 一台儀器逐點量測時，記錄各測點開始與結束時間（或量測時長）之表格。 |
| 儀器點位對應表 | 多台儀器同時量測時，記錄每台儀器放置於哪一測點之表格。 |
| 固定參考點 | 逐點量測時於量測前、中、後重複量測之同一位置，用以判斷量測期間濃度是否改變。 |
| 普通克利金法 | 依測點間距離關係推估未量測位置濃度之空間內插方法。本手冊固定採用線性變異函數，斜率 1、塊金值 0。 |
| 留一交叉驗證 | 每次移除一個測點，以其餘測點推估該點濃度，再與實測值比較，用以判斷分布圖之可信程度。 |
| RRMSE | 相對均方根誤差。留一交叉驗證之均方根誤差除以實測平均值，以百分比表示。 |
| MAPE | 平均絕對百分誤差。留一交叉驗證中各測點推估誤差占實測值百分比之平均。 |
| 熱區 | 圖面上濃度達「最低值加全距之 80%」以上之連續區域。 |
| 容許濃度 | 法規所定之勞工作業場所容許暴露標準。事業單位亦得自訂較嚴之管理值，本手冊統稱為管理值。 |

### 二、Skill 之內容

Skill 為一組提供大型語言模型依循之作業說明與計算程式。安裝後，使用者於對話中提及濃度分布圖、佈點、標準資料表、補點等內容時，模型即自動載入 Skill，依本手冊相同之步驟及參數執行，不需記憶指令或說出 Skill 名稱。Skill 之工作範圍至熱區、管理值分區及面積計算為止，不代為撰寫管理建議或結果報告。

Skill 由下列部分組成，使用者不需修改：

（一）作業說明（SKILL.md 及 references 資料夾）：各階段之步驟、判定門檻及應告知使用者之事項。

（二）計算程式（scripts 資料夾）：佈點、原始資料轉換、資料檢核、克利金製圖、交叉驗證、補點建議及漂移計算。所有計算均由程式執行，模型不得自行撰寫內插程式。

（三）空白範本（assets 資料夾）：標準資料表 v5.0、點位量測時間表 v1.0 及儀器點位對應表 v1.0。

### 一、以 Skill 辦理佈點規劃

（一）上傳平面圖，輸入提示詞 2，說明場域尺寸、原點、污染物及單位。

提示詞 2　範例

這是**【烘乾區】**的平面圖，實際大小是 X 方向**【30】**公尺、Y 方向**【26】**公尺，左下角為原點。我要量**【苯】**，單位**【ppm】**。請先判斷平面圖上哪些地方不能站（設備、樓梯等），給我確認，也告訴我你刻意沒有標的東西，再問我可能逸散的位置。

（二）Skill 會於平面圖上判斷障礙區，說明判斷理由及未標示之項目，並詢問可能逸散位置。使用者應逐項確認、修正或補充，得直接於平面圖上圈選逸散位置後回傳。確認時使用提示詞 3。

提示詞 3　範例

障礙區這樣可以，但**【烘乾機 C 出口端站】**實際只到 X**【26】**公尺；**【左上角的風扇是吊在天花板上】**，不用排除。可能逸散的位置是**【烘乾機 A 入口】**和**【換桶區】**，我在圖上圈起來了。請依此佈點，先給我佈點圖確認。

（三）Skill 依障礙區及逸散位置計算測點數並佈點，提供佈點圖供確認。確認後輸入提示詞 4，取得標準資料表（已嵌入佈點圖），並依量測方式取得點位量測時間表或儀器點位對應表。

### 二、平面圖及場域資訊取得注意事項

（一）量測區域之俯視平面圖可為jpeg、png、pdf等格式。CAD 圖應另存為 PDF；透視圖、立體示意圖及無比例之手繪圖無法對位，不得使用。

（二）確認場域之實際長度（X 方向）及寬度（Y 方向），單位為公尺。無法確認時，得以圖上一段已知長度（如柱距）作為比例依據。

（三）座標原點一律訂於場域圖面左下角，X 軸向右、Y 軸向上。現場人員應確認平面圖之方向與現場一致，避免量測時方向相反。

（四）平面圖之 X、Y 比例差異超過 3% 時，表示圖面未依比例繪製或框選範圍有誤，應先釐清。Skill確認圖面本身未依比例者，會以提供之X、Y 對平面圖進行調整，座標以實際尺寸為準，背景圖可能略有變形。

### 三、標示障礙區

Skill 會根據圖面判斷可能障礙區，並以灰色網格覆蓋，主要依據如下，使用者亦可自行標示，增加準確度。

（一）於平面圖上標示無法站立量測之區域，包括：

1\. 樓梯、電梯井、地坑。

2\. 設備本體及其基座，如烘乾機、槽體、馬達、捲料架、電氣箱。

3\. 設備前後端之附屬工作站。

4\. 地面軌道、輸送帶、溝槽、基礎。

5\. 牆、隔間、儲架。

6\. 人員無法進入之狹窄間隙，如設備與軌道之間。

（二）下列項目通常不列為障礙區：以斜視方式繪製之架空風管或排氣管、懸吊於天花板之風扇或送風機、尺寸線及標註線、柱線。無法判斷為落地或懸吊者，應至現場確認。

（三）障礙區以矩形或多邊形記錄其 X、Y 範圍（公尺），並以中文命名，名稱將顯示於圖面。

| 類別       | 常見位置                               |
|:-----------|:---------------------------------------|
| 設備接口   | 法蘭、閥件、取樣口、加料口、泵浦軸封   |
| 開放液面   | 槽體、浸泡槽、塗布頭、溶劑桶、廢液桶   |

### 六、決定測點位置

（一）測點以方格方式平均分布，位於方格中心。

（二）每一測點距障礙區邊緣至少 0.5 公尺。測點落於障礙區或其 0.5 公尺範圍內者，移至半個間距內最近之可站立位置；無法移出者刪除，並記錄刪除之測點。狹窄間隙內之測點無法同時距兩側 0.5 公尺，應刪除。

（三）測點座標記至小數點後一位（0.1 公尺），以利現場以步測或捲尺定位。

（四）測點編號自左下角開始，依 Y 方向由下往上分列，同一列由左至右，依序編為 P01、P02……。測點移位後，同一列之編號順序可能改變，交付現場人員時應說明編號方向。

（五）量測高度原則為 1.5 公尺（呼吸帶高度），例外者應於備註註明。

### 一、共同事項

（一）量測前確認儀器已校正，並記錄儀器型號、偵測極限及記錄間隔。

（二）將儀器時鐘與記錄用之手錶或手機對準。時鐘不一致時，事後無法依時間切出各測點之讀值。

（三）量測期間有換桶、清洗、開關門等臨時作業者，應記錄時間及位置。

（四）量測期間作業狀態應維持一致。作業狀態改變時，應分開記錄，必要時分別製圖。

### 二、一台儀器逐點量測

（一）開始量測前，先至固定參考點量測一次。

（二）依編號順序走訪各測點，宜以來回方式進行，避免一路由低濃度區往高濃度區單向前進。

（三）每點停留時間應一致，於點位量測時間表填寫每點之開始時間，及結束時間或量測時長（兩者擇一，均填寫時以結束時間為準）。時間格式得寫為 hh:mm:ss 或 YYYY-MM-DD hh:mm:ss。

（四）儀器到達測點後需反應時間，應停留足夠反應時間，該段讀值宜於整理時捨去，捨去秒數應於量測前決定並記錄。

（五）量測進行至一半及全部結束時，各回到固定參考點量測一次，並依第八章第五節判斷漂移。

（六）可請 Skill 提供點位量測時間表，如提示詞 4。

### 三、多台儀器同時量測

（一）量測前將全部儀器置於同一處，同時記錄數分鐘，比對儀器間讀值差異。

（二）依儀器點位對應表放置儀器。儀器編號須與儀器記錄檔之欄位名稱完全相同，儀器編號與測點編號通常不同，不得假設兩者順序一致。

（三）儀器放置後應連續記錄至濃度穩定，記錄長度宜達 30 分鐘以上，以利判斷穩定起點。

（四）設置室外或背景測點者，於對應表備註註明。是否扣除背景，應依實際需要決定，並記錄於標準資料表備註。

（五）儀器故障或未記錄者，該測點於對應表備註註明原因。

（六）可請 Skill 提供儀器點位對應表，如提示詞 4。

### 一、標準資料表格式及填寫規則

標準資料表為單一工作表「基本資料與量測濃度」。第 1 列為英文欄位代碼，供程式讀取，不得修改；第 2 列為中文欄名，得修改。填寫時應遵守下列規則：

（一）一份標準資料表只記錄一種污染物。濃度欄 c1、c2、c3 為同一污染物之重複量測紀錄，不是三種污染物。

（二）未量測之測點，濃度欄留空，並於備註寫明原因，不得填 0、N/A、ND、「—」或「無」。0 代表儀器確實讀到 0，會拉低周圍之推估濃度。

（三）對低於偵測極限者，濃度欄可留空，備註寫「\<LOD」，並於基本資料填入偵測極限（c_LOD）。製圖時以偵測極限除以根號 2 代入；此類測點超過全部測點三分之一時，低濃度區之形狀主要由代入值決定，應謹慎判讀。

（四）濃度欄只填數字，不加單位、千分位逗號或符號。

（五）不合併儲存格，不插入空白列或小計列。

### 二、多台儀器同時量測之資料

#### （一）以 Skill 辦理

1\. 上傳儀器匯出之原始記錄（第 1 欄為時間，其餘每台儀器一欄）及儀器點位對應表，輸入提示詞 5。

提示詞 5　範例

這是多台感測器同時記錄的**【苯】**資料，每**【10】**秒記一筆，感測器對應的點位編號在附檔的儀器點位對應表。請先幫我看濃度什麼時候開始穩定，用穩定後的平均當作各點濃度，整理成標準資料表。**【（有背景測點時）S-27 是室外背景，不要扣除，只列出來給我看。】**有問題先告訴我。

2\. Skill 會回覆濃度開始穩定之時間（穩定起點）、判定之理由，以及前一分鐘為何尚未穩定（例如某台儀器仍在下降）。使用者應對照現場紀錄確認該時段無臨時作業；如需改用其他時段，得直接告知 Skill，例如「改用 09:10 到 09:30 的平均」。

3\. 確認後，Skill 提供標準資料表，備註欄已寫明代表濃度之取得方式及平均時段。

4\. Skill 回報對應表有列、記錄檔卻沒有該欄之儀器時，表示該儀器未記錄，對應測點會留空；記錄檔有欄位、對應表未列者，則不納入。使用者應確認是否為儀器故障或對應表漏填。

#### （二）代表濃度之取得方式

1\. 各測點之代表濃度，取「穩定起點」至記錄結束之平均值。

2\. 穩定之判斷原則為：全部儀器之平均值已無明顯上升或下降、平均時段開頭沒有落在濃度變化之斜坡上，且沒有任何一台儀器仍有明顯趨勢。

3\. 整段記錄均未達穩定時，Skill 會改取最後時段之平均，並於備註註明「未達穩定」。

4\. 是否扣除背景濃度，應依實際需要決定，並記錄於標準資料表備註。

### 三、一台儀器逐點量測之資料

#### （一）以 Skill 辦理

1\. 上傳儀器匯出之連續記錄及填妥之點位量測時間表，輸入提示詞 6，並說明每點剛到達時要捨去幾秒之讀值。

提示詞 6　範例

現場濃度是用同一台**【PID】**逐點量的，儀器每**【10】**秒記一筆，各點的開始時間和量測時長寫在點位量測時間表裡。每個點剛到的前**【20】**秒讀值還不穩，請不要算進去，其餘取平均，整理成標準資料表。有問題先告訴我。

2\. Skill 會回覆記錄筆數、每點採用之時段及捨去秒數，並列出下列需確認之情形：

> （1）某點之平均時段超過下一點之開始時間，通常為量測時長填寫過長。
>
> （2）某點讀值筆數少於預期。
>
> （3）儀器記錄未涵蓋時間表之時段，通常為儀器時鐘或日期與手錶不一致。

3\. 使用者確認或更正時間表後，Skill 提供標準資料表，備註欄已寫明代表濃度之取得方式。

#### （二）代表濃度之取得方式

1\. 各測點之代表濃度，取該點開始時間至結束時間（或開始時間加量測時長）內讀值之平均，測點間移動時之讀值不納入。

2\. 每點剛到達時之讀值受儀器反應時間影響，得捨去，捨去秒數依量測前之決定，並記錄於備註。

3\. 未記錄各點時間，亦無固定之停留及移動時間者，無法判斷讀值屬於哪一測點，Skill 不會自行推測，會請使用者提供時間資料。

### 五、只有測點編號而無座標

#### （一）以 Skill 辦理

1\. 上傳當時之佈點示意圖或平面圖，及測點編號與讀值，輸入提示詞 8，說明場域尺寸及編號方向。

提示詞 8　範例

#### （二）注意事項

1\. 沒有座標不能製圖。Skill 不會假設測點為等距排列，無示意圖或平面圖時，會請使用者提供。

2\. 編號方向（起始角落、先往右或先往上）應確認清楚。已知逸散源者，熱區應位於逸散源附近；熱區遠離逸散源時，常為編號方向相反。

### 六、重複量測

（一）只量測一次者，只填 c1。

（二）量測多次者，依時間順序填入 c1、c2、c3，並於第 2 列中文欄名註明日期或時間（如「量測1_1111」）。製圖預設取平均；需要時得請 Skill 改取單次或最大值（保守估計）。

### 三、可疑高值之判斷

（一）濃度明顯高於其他測點者（大於第三四分位數加 3 倍四分位距），Skill 會列為可疑高值，但不會自動刪除。作業場所之高值常為欲找出之熱點。

（二）使用者應依下列四點判斷，並將判斷結果告知 Skill（如提示詞 10）：

1\. 是否鄰近已知逸散源。

2\. 重複量測是否仍偏高。

3\. 鄰近測點是否亦偏高。

4\. 量測時是否有臨時作業。

（三）相鄰數點均偏高者，應視為熱區。僅單一點異常偏高者，宜回現場確認或重測，並於該點附近補點。

（四）確定為異常而排除者，應告知 Skill 排除理由，理由會記錄於製圖參數紀錄中。需要比較時，得另畫一張排除該點之圖，正式之圖仍保留。

### 四、位於障礙區內之測點

測點座標落在障礙區內者，製圖時會被斜線遮蓋。Skill 不會自行移動測點，會請使用者確認屬下列何種情形：

（一）座標記錄錯誤：更正座標。

（二）儀器置於設備或平台上：保留，並於備註註明。

（三）障礙區繪製範圍大於實際：提供實際尺寸，由 Skill 修正障礙區範圍；僅知較小而無實際尺寸者，Skill 只調整含測點之邊緣，並註明為估計。

### 二、驗證方式

Skill 以留一交叉驗證檢驗圖面：每次拿掉一個測點，用其餘測點以相同方法推估該點濃度，再與實測值比較，全部測點輪流一次後，計算下列兩項指標：

| 指標 | 計算方式 | 意義 |
|:---|:---|:---|
| RRMSE | RMSE ÷ 實測平均值 × 100% | 以相對誤差計算，熱區附近之大誤差會完整反映，可看出主要濃度差異是否被掌握 |
| MAPE | 平均（｜推估 − 實測｜÷ 實測）× 100% | 一個測點通常偏差之百分比；低濃度測點之誤差可能會被放大 |

兩項指標應同時檢視，並參考絕對誤差最大之 3 個測點。

### 三、判定原則

（一）RRMSE 或 MAPE 任一項達 20% 以上者，建議補點。

（二）兩項均低於 20% 者，得視需要補點。熱區濃度接近管理值、管理決策取決於分區邊界，或需要較精細之圖面時，仍宜補點。

（三）補點應以濃度梯度高處為優先。在濃度平緩之區域補點，雖可使兩項指標下降，但無法改善整體之推估。

### 四、補點位置

Skill 依下列順序提出補點位置：

（一）最高點周圍之十字點：於最高點上下左右各半個測點間距處補點，確定峰值之位置及高度。

（二）高濃度梯度中點：相鄰兩點濃度差異大於全場標準差者，於兩點中間補點。

（三）涵蓋不足處：測點稀疏、推估不確定性最大之區域。

補點均距障礙區邊緣至少 0.5 公尺，座標記至 0.1 公尺。需移動 2 公尺以上才能避開障礙區者，表示該處無法進入，Skill 會刪除並說明。補點建議圖只標示原有測點（藍色圓點）及建議補點（紅色菱形），不呈現濃度，以便現場定位。

### 五、固定參考點濃度漂移

一台儀器逐點量測時，可以固定參考點於量測前、中、後之讀值判斷量測期間濃度是否改變。逐點量測之點位量測時間表中有重複量測同一點者，Skill 會直接計算漂移。

將三次讀值告知 Skill，輸入提示詞 16，Skill 會計算漂移並提供備註文字。

提示詞 16　範例

固定參考點在量測前、中、後的讀值分別是**【0.52】**、**【0.55】**、**【0.50】【ppm】**，時間是**【09:00】**、**【09:20】**、**【09:40】**。請幫我判斷漂移是否可以接受，並給我要寫進備註的文字。

漂移（%）＝（最大值 − 最小值）÷ 平均值 × 100%，判定方式如下：

| 漂移       | 處理方式                                   |
|:-----------|:-------------------------------------------|
| 10% 以下   | 可接受，全部測點視為同一時段               |
| 10% 至 30% | 記錄於備註，判讀時以相對高低為主           |
| 超過 30%   | 建議重新量測、縮短總量測時間，或分時段量測 |

### 二、熱區判讀

（一）熱區為圖面濃度達「最低值加全距之 80%」以上之連續區域，最多列出 5 處。鄰近設備依熱區峰值至設備邊緣之距離排序，最近者列第一。

（二）熱區鄰近預判之逸散位置者，可佐證該處為逸散源，宜列為優先檢查對象。

（三）熱區不在任何已知設備旁者，應先核對測點座標及編號方向；確認無誤時，可能為未知之逸散源、通風死角，或氣流將污染物帶往他處。

（四）熱區僅由單一測點構成者，其位置及高度不確定，應依第八章補點。

（五）熱點之濃度應以實測值為準，不得由圖面顏色讀取。

### 三、管理值分區

（一）提供容許濃度或自訂管理值時，Skill 預設依暴露分級管理之概念，將場域分為三區：低於容許濃度（PEL）或管理值之 50%；50% 至 100%；達 100% 以上。使用者亦得自訂分區界限，例如「用 0.3 和 0.6 ppm 分區」。

（二）各區面積及比例均扣除障礙區。

### 四、管理應用

事業單位得參考下列方式運用分布圖：

（一）達管理值以上之區域：確認逸散源，評估密閉、局部排氣或製程改善；改善後以相同測點再量測一次，分別製圖比較。

（二）管理值 50% 至 100% 之區域：檢視整體換氣及作業動線，並作為次年度作業環境監測採樣點位之參考。

（三）作業環境監測測點初步規劃：對主要熱區、可能逸散源等分佈圖中濃度較高區域，得考慮設置監測點。

（四）圖面驗證未達標準（RRMSE 或 MAPE 達 20% 以上）者：管理判斷以熱區位置為主，補點後再重新製圖。

（五）作為作業環境監測計畫初步危害分析之參考時，應註明分布圖之使用限制。
