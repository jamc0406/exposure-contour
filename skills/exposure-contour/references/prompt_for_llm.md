# 跨模型標準提示語 v2.0（功能 R6）

**用途**：給不使用 Claude 的單位，貼進 ChatGPT、Gemini 等具程式執行功能的模型，依與本 Skill、ConcTour 相同的設定製作濃度分佈圖。
**使用方式**：先上傳標準資料表（xlsx 或 csv），再貼上 M1 到 M5 全文。`[ ]` 內為選填變數，不需要就刪掉那一行。
**資安提醒**：上傳前把場域名稱改成代號（例如「A 廠塗布區」），不要上傳含廠名、製程名稱的平面圖。

## M1　資料說明

我上傳的檔案是作業場所有害物濃度量測資料，格式如下：

- 第 1 列為英文欄位代碼，第 2 列為中文欄名，資料自第 3 列起
- 左半部 A–D 欄為基本資料：`field_code` / `field_name` / `value` / `unit`。`field_x_m`、`field_y_m` 為場域尺寸（公尺），`c_name`、`c_unit` 為污染物名稱與單位，`c_LOD` 為偵測極限
- 右半部 F–L 欄為測點資料：`point_id`、`x_m`、`y_m`、`c1`、`c2`、`c3`（同一污染物的重複量測）、`note`
- 座標原點為場域左下角，X 向右、Y 向上，單位公尺

請先讀取檔案，回報：場域尺寸、污染物與單位、測點數、濃度範圍與平均值。**先不要畫圖。**

## M2　資料檢核

每個測點的代表濃度取 c1–c3 中有填值者的算術平均。備註寫 `<LOD` 且濃度留空者，以 c_LOD ÷ √2 代入。濃度留空且無 `<LOD` 者視為未量測，排除。

請檢查並回報下列項目，有問題就指出，不要自行修補後略過：

1. 數值欄是否混入文字（如 `N/A`、`ND`）
2. 濃度是否有負值
3. 濃度是否有 0（請列出，保留計算，由我確認是否為真實讀值）
4. 座標是否超出場域範圍
5. 測點編號是否重複
6. 低於偵測極限的點數，是否超過全部測點的三分之一
7. 可疑高值：濃度大於 Q3 + 3 × IQR 者列出，**不要剔除**

## M3　插值與製圖

請用 Python 完成，並遵守下列規定。

**插值方法**：普通克利金（Ordinary Kriging），變異函數固定為 **linear、slope = 1、nugget = 0、異方性比 1**。不要讓套件自動擬合變異函數，不要改用其他模型。
（若使用 PyKrige：`OrdinaryKriging(x, y, z, variogram_model='linear', variogram_parameters={'slope': 1, 'nugget': 0})`）

**網格**：範圍為整個場域 0 至 field_x_m、0 至 field_y_m（不要只取測點外接矩形）；長邊 120 個節點，短邊依長寬比等比例，至少 10 個節點。

**輸出限制**：

- 濃度不得為負，低於 0 者截為 0
- 色階採 **Jet**（深藍→藍→青→黃→紅→深紅，Plotly Jet 定義：0 `#000083`、0.125 `#003caa`、0.375 `#05ffff`、0.625 `#ffff00`、0.875 `#fa0000`、1 `#800000`）
- 分級級距取整（如 5、10、25、50、0.05），約 10 級
- **不要**另外標示外插區
- [障礙區：下列矩形以白底斜線遮蓋，不呈現濃度：名稱、x0、y0、x1、y1]
- [OEL：在濃度 ____ 處畫一條粗紅色等值線，標註「OEL」，並回報 ≥ OEL 的面積與面積比、超過 OEL 的測點數]

**圖面元素**：場域邊界、測點位置（黑點）、濃度色階面、細等值線、色階圖例（含污染物名稱與單位）、座標軸標示（公尺）。

## M4　回報

1. 實測值統計：有效點數、最小、最大、算術平均、中位數、標準差、幾何平均、幾何標準差、變異係數
2. 插值後全場的最小值、最大值、平均值；圖面最高值的座標
3. 留一交叉驗證（每個測點輪流拿掉一次，用其餘測點以相同設定推估）：
   - RRMSE = RMSE ÷ 實測平均 × 100%
   - MAPE = mean(|推估 − 實測| ÷ 實測) × 100%（只計實測 > 0 的點）
   - 絕對誤差最大的 3 個點（實測、推估、誤差、誤差佔實測 %）
   - RRMSE 或 MAPE 任一項 ≥ 20% 時註明「建議補點」，兩項都 < 20% 註明「視情況補充」
4. 你實際使用的 Python 套件與版本

## M5　若圖面有問題

若出現下列情形請告訴我，不要自行調整後當作沒事：

- 圖面最高值明顯低於實測最高值
- 熱點位置與實測最高點明顯不符
- 輸出幾乎是單一顏色（常數場）
- 中文字顯示為方框或亂碼

## 附註：為什麼固定 linear、nugget = 0

普通克利金搭配無 nugget 之線性變異函數時，克利金權重與 slope 大小無關，因此不需由資料估計任何參數，測點少時仍可穩定求解；nugget 為 0 時曲面於測點處連續，不會系統性低估峰值。此設定與 Surfer 克利金預設值、ConcTour 完全相同（網格差在 10⁻⁶ 以下）。期中報告比較五種變異函數設定，此設定於各測點密度下之擬合度指標中位數均為最佳或次佳；讓套件自動擬合時，高斯型等模型在測點密集處會出現近奇異、推估值失控的情形。
